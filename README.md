# Simple Photo Gallery Site

This repository provides a template for a simple photo gallery.
Major usages include sharing photos with family and/or friends.

# Usage

1. Prepare image files under `images/`.
2. Prepare thumb nail files under `thumbs/`.
3. Create a list of files as `data.json`.
4. Place `index.html`, `script.js`, `style.css`, `data.json`, and image files on your web server.

Example `data.json` is as below.
```json
[
    { "thumb": "thumbs/0001.jpg", "full": "images/0001.jpg" },
    { "thumb": "thumbs/0002.jpg", "full": "images/0002.jpg" },
    { "thumb": "thumbs/0003.jpg", "full": "images/0003.jpg" }
]
```
